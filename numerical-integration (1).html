Numerical integration

Approximate a definite integral with the trapezoidal rule and Simpson's rule, either with a fixed number of subintervals or by letting the program choose the step size to reach a tolerance.

Inputs

Simpson's rule needs an even n. An odd value is raised by one.
Both methods halve h until the estimated error is below this value.

Formulas

h = (b - a) / n
T = h/2 [f(x0) + 2 Σ f(xi) + f(xn)]
S = h/3 [f(x0) + 4 Σ f(odd) + 2 Σ f(even) + f(xn)]
